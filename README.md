A machine learning investigation into pneumonia detection, completed as university coursework. This project evaluates multiple traditional machine learning models on a pneumonia dataset, including:

- Decision Trees & Random Forest
- K-Nearest Neighbours (KNN)
- Naive Bayes
- Support Vector Machines (SVM)
- Logistic Regression (SGD with log-loss)

The analysis focuses on ROC-AUC as the primary evaluation metric to handle class imbalance and ensure reliable discrimination between positive and negative cases. Includes hyperparameter tuning via grid search and an extension exercise exploring CNNs and ViTs for X-ray image classification.
